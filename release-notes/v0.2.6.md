Unzip the one for your computer and double-click `stowaway`.

| Download | For |
|---|---|
| `stowaway-windows.zip` | Windows 10/11, x64 |
| `stowaway-mac.zip` | Apple Silicon Macs (M1 and newer), macOS 13+ |
| `stowaway-mac-intel.zip` | **Intel Macs, macOS 12+ (new)** |
| `stowaway-linux.zip` | x64 Linux with glibc 2.34+ (Ubuntu 22.04+, Debian 12+, Fedora 35+) |

What's new:
- **Intel Macs.** Older Intel MacBooks and iMacs (often 8 GB with a fast SSD) can now run stowaway. Like the Windows and Linux downloads, it includes the compatible engine for processors without AVX2.
- **Built and tested by GitHub.** Every download is now built from this repository by GitHub Actions and tested end to end before release: download, pack, slim and generate with a tiny test model, with both the normal and the compatible engine. Anyone can check how it was built.
