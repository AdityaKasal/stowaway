Unzip the one for your computer and double-click `stowaway`.

| Download | For |
|---|---|
| `stowaway-windows.zip` | Windows 10/11, x64 |
| `stowaway-mac.zip` | Apple Silicon Macs (M1 and newer), macOS 13+ |
| `stowaway-mac-intel.zip` | Intel Macs, macOS 12+ |
| `stowaway-linux.zip` | x64 Linux with glibc 2.34+ (Ubuntu 22.04+, Debian 12+, Fedora 35+) |
| `stowaway-linux-arm64.zip` | 64-bit ARM Linux: Raspberry Pi 5 and 4, ARM Chromebooks, ARM laptops |

What's new:
- **Downloads are checked.** After a model downloads, stowaway checks its exact size and SHA-256 against the values Hugging Face publishes, before it modifies anything. A damaged or cut-short download is fetched again once, and if it's still wrong you're told why, instead of getting a model that quietly talks nonsense. This takes about a minute for the biggest models. If Hugging Face's checksum can't be reached, the check is skipped with a note.
