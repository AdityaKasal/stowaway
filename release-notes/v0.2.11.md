Unzip the one for your computer and double-click `stowaway`.

| Download | For |
|---|---|
| `stowaway-windows.zip` | Windows 10/11, x64 |
| `stowaway-mac.zip` | Apple Silicon Macs (M1 and newer), macOS 13+ |
| `stowaway-mac-intel.zip` | Intel Macs, macOS 12+ |
| `stowaway-linux.zip` | x64 Linux with glibc 2.34+ (Ubuntu 22.04+, Debian 12+, Fedora 35+) |
| `stowaway-linux-arm64.zip` | **64-bit ARM Linux (new): Raspberry Pi 5 and 4, ARM Chromebooks, ARM laptops** |

What's new:
- **ARM Linux.** A Raspberry Pi 5 with 8 GB (about $80) can now run these models. Like the PC builds, it has two engines: a fast one for ARMv8.2 chips with dot-product instructions (Pi 5, most ARM laptops and Chromebooks from the last few years) and a compatible one for older chips (Pi 4), picked automatically. Built and tested end to end on GitHub's ARM machines. Speed depends heavily on the storage: a Pi's microSD card is far too slow, so use an NVMe SSD (on the Pi 5, through an M.2 HAT) or a USB 3 SSD.
