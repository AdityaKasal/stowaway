What's new:
- **Up to 2-3x faster on typical 8 GB laptops, still CPU-only.** stowaway was keeping too much memory free "for safety". Measurements found the real limit (about 0.8 GB), so the expert cache now gets the rest. On a simulated 8 GB Windows laptop (~5 GB free), Qwen 35B went from 2.4 to 4.9 words/s, and to 7.2 with `--fast`: the same speed a GPU gave in the same test. gpt-oss-120b on 8 GB: 2.3 -> ~2.7 words/s. Details in RESULTS.md, section 27.
- On machines with under 7 GB free, the conversation window is 3,072 tokens with leaner buffers, so more memory goes to speed.
