Unzip the one for your computer and double-click `stowaway`.

| Download | For |
|---|---|
| `stowaway-windows.zip` | Windows 10/11, x64 |
| `stowaway-mac.zip` | Apple Silicon Macs (M1 and newer), macOS 13+ |
| `stowaway-mac-intel.zip` | Intel Macs, macOS 12+ |
| `stowaway-linux.zip` | x64 Linux with glibc 2.34+ (Ubuntu 22.04+, Debian 12+, Fedora 35+) |
| `stowaway-linux-arm64.zip` | 64-bit ARM Linux: Raspberry Pi 5 and 4, ARM Chromebooks, ARM laptops |

What's new:
- **Delete a model from the menu.** Press `d`, pick the model, type `yes`. It frees 12-92 GB without hunting for hidden folders.
- **A report when something goes wrong.** If a model fails to start, stowaway saves `stowaway-report.txt` (the machine's basics, the error, and the last lines of the engine's log; no personal files) and says where it is, so you can send it to whoever helps you.
